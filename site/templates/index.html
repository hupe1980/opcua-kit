Read a variable

Address a signal by namespace URI and identifier. Each sample carries the server’s status and the available timestamps alongside its value.

Set up the session
Rust · client.read_scalar
use opcua_kit::{NodeId, Sample};

let axis = NodeId::new(
    "urn:factory:line-1", "s=AxisPosition",
)?;
let sample: Sample<f64> =
    client.read_scalar(&axis).await?;
